# Foto del sito Collisioni ETS

Inserisci qui le foto (di proprietà di Collisioni ETS) con questi nomi esatti.
Il sito le mostra automaticamente; se un file manca, appare un placeholder brandizzato.

| File                | Dove appare                          | Formato consigliato        |
|---------------------|--------------------------------------|----------------------------|
| hero.jpg            | Sfondo grande della sezione iniziale | orizzontale, ~2000×1200    |
| comunita.jpg        | Sezione "Chi siamo"                  | verticale/quadrata, ~1000  |
| presepe.jpg         | Card progetto Presepe Vivente        | orizzontale, ~1200×900     |
| carnevale.jpg       | Card progetto Carnevale              | orizzontale, ~1200×900     |
| anziani.jpg         | Card progetto Centro Anziani Attivi  | orizzontale, ~1200×900     |
| castello.jpg        | Banda fotografica a tutta larghezza  | orizzontale, ~2400×1000    |
| logo.png / logo.svg | (opzionale) logo ufficiale gabbiano  | PNG trasparente o SVG      |

Consigli: JPG per le foto, sotto ~500 KB ciascuna quando possibile.
